# Choix et ouverture du projet

## Type de projet

Ce projet est un projet full-stack

## Informations sur le projet
### Nom et objectif
Ce projet se nomme NBA Fan Finder, il a pour but de mettre en relation des utilisateurs fan de NBA pour chatter entre eux à propos de leur équipe favorite.

### Technologies
Les techonolgies utilisées sont Java Springboot et React.

### État d'avancement
Fonctionnalités principales implémentées, tests à compléter.

### Présence Front/Back/BDD
Les 3 couches sont présentes sur le projet.
